# Til lægen – nye spørgsmål til FAQ'en på behandlingssiderne

**Dato:** 11. november 2026 · **Status:** afventer svar. Intet er ændret i FAQ'en endnu.

FAQ'en gentager i dag svar, der står længere oppe på samme side (holdbarhed, effekt,
efterbehandling). Vi vil skifte 2–3 spørgsmål pr. side ud med nogle, siden ikke svarer på.
Skriv 1–3 sætninger pr. spørgsmål – eller streg dem, der ikke giver mening.

| Side | Nyt spørgsmål |
|---|---|
| Botox | Kan jeg arbejde dagen efter? |
| Botox | Kan man se på mig, at jeg har fået botox? |
| Botox | Hvad sker der, hvis jeg stopper med botox? |
| Filler | Kan man mærke filleren bagefter? |
| Filler | Hvor meget filler skal jeg bruge første gang? |
| Filler | Kan jeg flyve eller træne dagen efter? |
| Skinbooster | Kan jeg få skinbooster og botox eller filler samme dag? |
| Skinbooster | Hvor lang tid før en fest skal jeg behandles? |
| Mesoterapi | Hvad er forskellen på mesoterapi og skinbooster? |
| Mesoterapi | Hjælper mesoterapi mod hårtab? |
| Microneedling | Hvor mange behandlinger kræver akne-ar typisk? |
| Microneedling | Kan microneedling bruges på mørk hud eller om sommeren? |

**Udgår, når svarene er kommet** (står allerede andre steder på siden): holdbarhed,
"hvornår ses effekten", "hvad bør jeg undgå efter behandlingen".
